# PDF-ToolKit 🛠️

A professional-grade, fast, and secure PDF tool suite built for modern workflows. Simplify your document management with a suite of tools designed to be free, easy to use, and require no installation.


## ✨ Features
- **Merge PDF**: Combine multiple PDF files into one single document seamlessly.
- **Image to PDF**: Convert JPG and PNG images into high-quality PDF files.
- **Page Deletor**: Easily remove specific pages or ranges from your PDF documents.
- **PDF Protection**: Secure your sensitive files with industry-standard password encryption.


## 💻 Tech Stack
- **Frontend**: [React](https://react.dev/) (v18)
- **Icons**: [Lucide React](https://lucide.dev/)
- **PDF Processing**: [pdf-lib](https://pdf-lib.js.org/), [zgapdfsigner](https://www.npmjs.com/package/zgapdfsigner)
