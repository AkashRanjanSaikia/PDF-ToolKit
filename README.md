# PDF-ToolKit 🛠️

A professional-grade, fast, and secure PDF tool suite built for modern workflows. Simplify your document management with a suite of tools designed to be free, easy to use, and require no installation.


## 🚀 Live Demo
Check out the live application here: [PDF-ToolKit Live](https://pdf-tool-kit-mu.vercel.app/) 


## ✨ Features
- **Merge PDF**: Combine multiple PDF files into one single document seamlessly.
- **Image to PDF**: Convert JPG and PNG images into high-quality PDF files.
- **Page Deletor**: Easily remove specific pages or ranges from your PDF documents.
- **PDF Protection**: Secure your sensitive files with industry-standard password encryption.


## 💻 Tech Stack
- **Frontend**: [React](https://react.dev/) (v18)
- **Icons**: [Lucide React](https://lucide.dev/)
- **PDF Processing**: [pdf-lib](https://pdf-lib.js.org/), [zgapdfsigner](https://www.npmjs.com/package/zgapdfsigner)


## 🛠️ Local Setup
Follow these steps to get the project running on your local machine:

### 1. Clone the Repository
```bash
git clone https://github.com/AkashRanjanSaikia/PDF-ToolKit.git
cd PDFToolKit
```

### 2. Install Dependencies
Make sure you have [Node.js](https://nodejs.org/) installed.
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```
The application will be available at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```

## 🔒 Security
All PDF processing is done locally in your browser. Your files are never uploaded to any server, ensuring maximum privacy and security for your documents.
